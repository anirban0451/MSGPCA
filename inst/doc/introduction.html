Introduction to MSGPCA

MSGPCA decomposes each observations-by-features matrix into shared and local programs, \(Y_m\approx F_{s,m}W_s^T+F_{l,m}W_{l,m}^T\). Shared loadings are common; local loadings vary by slice. Loading columns are orthonormal and local loadings are orthogonal to the shared space. Signs, rotations and allocation ambiguities remain. Scores are graph-smoothed using sparse shifted-Laplacian solves.

Inputs and preprocessing

Provide a list of abundance matrices, with common molecular feature identities in identical order, and corresponding coordinate matrices with matching rows. Slice sizes and coordinates may differ; no alignment is necessary. The fitter never normalizes, centers, scales or transforms inputs. Choose preprocessing appropriate to the assay. Sparse inputs are accepted, but initialization, residuals and feature covariances can densify.

Graphs and diagnostics

Mutual k-NN is default; graph_type='union' includes either directed neighbor relation. k_shared and k_local specify separate graph sizes, while n_shared and n_local specify factor dimensions. Supplied graph entries are combinatorial Laplacians, or list(type='adjacency',matrix=A). Disconnected components and isolated vertices are supported. With zero smoothing and no coordinates, active scores are unregularized. Zero factor dimension disables a component. Diagnostics include initialization as iteration zero, every complete penalized objective and increases; the original shared update does not guarantee monotonic descent. Final scores and loadings always describe the same state.

Spatial domain detection

plot_clusters(gmm)

#> [1] "4" "1" "4" "3" "3" "3"

Shared clustering pools scores across slices; local clustering is independent and its cluster identifiers are not aligned. Scores are not implicitly scaled. Use factors=2:5 only with a scientific justification fixed independently of truth. GMM covariance models are selected by mclust and retained in gmm_model.

Refinement is adapted from SpatialPCA (Shang and Zhou, 2022, doi:10.1038/s41467-022-34879-1), distributed under GPL >=3. It uses one sequential pass, the focal observation and four (square) or six (hexagon) neighbors, with the original strict frequency rule. Ties use observation order. Conventional Visium uses hexagon. The shape does not validate tissue geometry. Duplicates and insufficient observations are errors. The default exact k-NN/radius-query implementation retrieves all boundary ties and resolves them by observation order; a rowwise reference is available via engine='reference'. Memory is linear; worst-case distance work is quadratic. Set refine=FALSE to retain raw assignments only.

Loadings define molecular metafeatures; scores show their spatial activity. Large loadings do not imply statistical significance. Local factor column numbers across slices do not imply common programs. Reconstructions remain on the supplied scale and are not automatically original counts. There is no unobserved-location prediction method.
